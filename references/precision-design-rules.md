# 人像精确设计与局部修改规则

在用户只给气质词、需要保留既有人物、迁移妆容、制造不同角色，或反馈画面“不自然”时使用本参考。目标是把抽象感受翻译成可见、可修改、可验证的设计参数。

## 1. 把脸部结构拆成独立轴

不要让一个含糊大词替模型决定整张脸。分别描述以下关系：

- **整体比例**：面部长宽、上中下庭比例、额头高度与饱满度。
- **眉眼骨相**：眉骨起伏、眼窝深浅、眉眼间距；眉骨属于结构，眉毛属于妆发，不能混写。
- **颧部**：颧骨位置高低、横向宽度、前突程度、面颊软组织饱满度分别控制。
- **下颌与下巴**：下颌相对颧部的宽度、转折圆锐、下巴长短、圆尖、前突或后缩分别控制。下巴短不等于后缩。
- **眼鼻唇**：眼裂长度、眼皮形态、眼尾方向、虹膜颜色；鼻梁高度与宽度、鼻尖形态、鼻翼体量；嘴唇宽度、上下唇厚度、唇峰和唇缘。

柔和的脸同样需要结构。平缓眉骨、较浅眼窝、饱满面颊和圆缓下颌，都是明确选择；不要一写“骨相”就自动变成深眼窝、尖下巴和高颧骨。

## 2. 气质与五官解耦

一种气质可以落在不同的脸上。圆脸可以清冷，单眼皮可以甜美，成熟脸也可以温柔治愈。

当用户已有喜欢的脸：

1. 先锁定面部比例、眉眼、鼻唇、肤色和辨识点。
2. 优先通过妆容、表情、发型、服装、光线和构图靠近目标气质。
3. 只有用户明确要求改脸时，才调整结构轴。

## 3. 妆容必须写到画面落点

用五个维度描述每个妆容重点：

- **颜色**：暖粉、灰紫、桃红、砖红等，并写清冷暖和饱和度。
- **质地**：透明、水润、柔雾、细闪、缎光。
- **位置**：双颊中央、颧部上方、外眼角下方、眼窝或睫毛根部。
- **方向**：横向铺开、向太阳穴延伸、沿天然唇形或眼尾短暂上扬。
- **边缘**：柔和渐隐、轮廓清楚但不生硬，或图形化锐利。

例如不要只写“桃粉腮红”，可写为：

> 透明暖粉腮红轻铺在双颊中央，向外侧轻微晕染，边缘柔和渐隐，保留面颊的自然饱满感。

如果只想让妆容变柔和，优先降低眼线锐度、软化眉头、减弱唇缘和腮红边界；不要顺带替换脸型、肤色和人物身份。

## 4. 局部修改采用“锁定 + 单变量”

先把用户的要求重述为两栏：

- **锁定项**：五官、骨相、肤色、发型、镜头、光线等未被要求改变的内容。
- **变化项**：本轮唯一需要改变的属性及其新值。

随后输出完整的新 Prompt，而不是只给一个补丁句。每轮优先改变 1–3 个变量；若结果仍有漂移，减少变量并重复关键锁定项。

示例：

> 保留人物的面部比例、眉眼、鼻唇、肤色、发型、构图和光线，只把口红改为低饱和酒红色；保持原有唇形与柔润缎光质地。

## 5. 妆容迁移不迁移身份

参考图只用于借妆时：

1. 提取主色、质地、线条方向、相对落点和边缘软硬。
2. 将这些参数应用到目标人物的既有面部结构上。
3. 明确保留目标人物的五官、骨相、肤色与辨识点。
4. 不把参考图直接作为身份垫图，不声称能够绝对复刻妆容效果。

## 6. 同妆不同脸要有结构差异

保持妆容的主色、质地、线条方向和相对落点一致；人物差异必须来自至少三项结构变化：

- 面部长宽比或三庭比例
- 眼裂、眼皮或眼距
- 鼻梁、鼻尖或鼻翼
- 颧部高度、宽度或面颊体量
- 下颌转折、下巴长度或前后位置

换发型、换衣服、换背景不能被当作“不同脸”。

## 7. 把“自然一点”翻译成可执行反馈

“自然”通常由表情、动作、构图和光线共同产生。根据问题选用具体改法：

- **笑容过度**：嘴唇轻合、不露齿、嘴角只留一点笑意、脸颊放松。
- **眼神表演感强**：视线略离开镜头，或闭眼感受阳光；不要同时改变五官。
- **姿势僵硬**：加入正在发生的轻动作，例如抬手挡光、整理头发、转身回望。
- **脸占比过大**：镜头后退，改为半身或四分之三身构图，保留环境关系。
- **AI 棚拍感强**：使用朋友随手拍到的瞬间、轻微构图偏移、真实皮肤纹理和不过度均匀的自然光。

修改时点名哪里不对，再把它改成可见参数；不要用一个“更自然”让模型重新设计整个人物。

## 8. 历史与文化造型

若用户要求唐风、汉服或其他历史文化风格，区分“风格化创作”和“严格历史复原”。默认按审美化人物创作处理；只有用户明确要求考据时，才需要核验年代、妆制、发式、服饰和配饰，不要把风格化结果称为历史复原。
